#  Retail Sales & Customer Analytics Project

## Project Overview
This project provides an end-to-end data analysis solution for a retail e-commerce store. It covers data exploration and cleaning using **SQL**, performance and customer metric calculations using **DAX**, and dynamic reporting via an interactive **Power BI Dashboard**.

---

##  Repository Structure
- `SQL_Scripts/`: Contains structured SQL scripts for data exploration, cleaning, and analysis.
  - `01_data_exploration.sql`: Data profiling, row counts, and anomaly detection.
  - `02_business_analysis.sql`: Business queries, revenue trends, and ranking metrics.

---

## Tools & Technologies
- **SQL Server / MySQL**: Data exploration, cleaning, CTEs, and Window Functions.

---

##  Key Insights & KPIs
- **Financial Performance**: Calculated accurate Net Revenue, Total Cost, Net Profit, and Discount Amounts for completed orders.
- **Customer Segmentation**: Analyzed high-performing customer groups (Consumer vs. Corporate) using Scatter Plots and ranking functions.
- **Product Trends**: Identified top-selling products and categories impacting profitability.
